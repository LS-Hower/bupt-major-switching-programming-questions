有一些足球队，你要对它们排序。

第 $1$ 行输入一个数 $n$ 。

第 $2$ 行至第 $n+1$ 行，每行表示了一个足球队的信息。也就是说，对于 $2 \le i \le n+1$ ，第 $i$ 行表示第 $i-1$ 个足球队的信息，分别是名称 $s_{i-1}$ 和分数 $a_{i-1}$ 。名称和分数已经用空格隔开。

请将这些足球队排序。先按分数排序，分数大的靠前。如果有分数相同的，则名字字典序小的靠前。

将排好序的足球队的名字和分数逐行输出，一行一个。名字和分数之间仍要有空格。

## 示例

输入：

```text
5
ParisSG 92
Juventus 86
Inter 81
ACMilan 81
Bayern 92
```

输出：

```text
Bayern 92
ParisSG 92
Juventus 86
ACMilan 81
Inter 81
```

## 数据范围

- $1 \le n \le 30$
- $1 \le |s_{i}| \le 31$ ，对于 $1 \le i \le n$ 。在这里， $|s|$ 表示字符串 $s$ 的长度。
- $1 \le a_{i} \le 1000$ ，对于 $1 \le i \le n$
