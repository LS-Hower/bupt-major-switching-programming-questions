输入一个整数 $n$ 。按顺序打印从 $n$ 到 $1$ 的所有整数，一行打印一个。共 $n$ 个整数，共 $n$ 行。

要求：要使用递归，不能使用循环。

准确地说，你的程序不能使用语言所提供的迭代（循环）流程控制结构，也不能使用能力等于或强于迭代的结构和标准库组件，但 **可以** 使用递归和分支结构。

例如，若你使用 C 或 C++ 语言，则：

- 不允许使用：
  - `for` 、 `while` 和 `do` ，因为它们是迭代结构。
  - `goto` 和库函数 `longjmp()` ，因为它们的能力强于迭代结构。
  - （C++）标准库中的 `ranges` 库，因为里面的组件已经具备迭代结构的计算能力。
- 允许使用：
  - 函数递归调用自己。
  - `if` 、 `else` 和 `switch` ，因为它们是分支结构。
  - `return` 和 `break` ，尽管后者是因为允许使用 `switch` 而被允许使用的。

## 示例

输入：

```text
8
```

输出：

```text
8
7
6
5
4
3
2
1
```

## 数据范围

- $1 \le n \le 1000$
