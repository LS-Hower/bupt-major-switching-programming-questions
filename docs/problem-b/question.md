输入一个整数 $n$ 。按顺序打印从 $n$ 到 $1$ 的所有整数，一行打印一个。共 $n$ 个整数，共 $n$ 行。

你的程序不能使用语言中的迭代（循环）流程控制结构，而是应该使用 **递归** 。

例如，若你使用 C 或 C++ 语言，则：

- 不允许使用 `for` 、 `while` 和 `do` ，因为它们是迭代结构。
- 不允许使用 `goto` 和库函数 `longjmp()` ，因为它们的能力强于上述迭代结构。
- 允许使用 `if` 、 `else` 和 `switch` ，因为它们是分支结构。
- 允许使用 `return` 和 `break` ，尽管后者是因为允许使用 `switch` 而被允许使用的。
- 允许函数递归调用自己。

## 示例

输入：

```text
8
```

输出：

```text
8
7
6
5
4
3
2
1
```

## 数据范围

- $1 \le n \le 1000$
