输入将以类似邻接矩阵的形式给出一个顶点为 $1$ 至 $n$ 的加权无向完全图，矩阵中的数即为边的权重。准确地说：

- 第 $1$ 行输入一个数 $n$ 。
- 第 $2$ 行至第 $n+1$ 行，每行都有 $n$ 个数。考虑第 $i$ 行，其中的 $n$ 个数为 $w_{i-1, 1}, w_{i-1, 2}, \ldots, w_{i-1, n}$ 。

在这里， $w_{i, j}$ 即表示 $i$ 和 $j$ 这两个顶点所连边的权重。当然， $w_{i, j} = w_{j, i}$ 。

对于顶点集 $V = \{1, 2, 3, \ldots, n\}$ ，我们可以将其划分为两部分 $A$ 和 $B$ 。也就是说：

- $A \cap B = \varnothing$ ；
- $A \cup B = V$ 。

可以任意选择划分方式，只要满足上述条件。

求：

$$
\max \sum_{a \in A} \sum_{b \in B} w_{a, b}
$$
